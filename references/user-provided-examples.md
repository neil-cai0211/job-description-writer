# 用户提供的 JD 参考样例

以下两份样例由用户提供，分别代表更有感染力的销售招聘文案和更严谨的技术管理岗位文案。它们用于学习结构、信息组织和语气，不是当前薪酬政策、公司制度或其他岗位事实的默认来源。

样例中的薪资、提成、收入、业绩、客户群、工作时间、福利、团队规模、技术栈、经历年限、公司名称和系统指标，都只能在对应招聘中重新确认后使用。没有确认时标为待补充或省略。可以整理重复内容和明显的标点问题，但不能改动事实、数字或条件。

## 电话销售代表

招聘标题与简介

【挑战高薪+双休】跨境电话销售顾问，寻找下一个销冠；无需出海，轻松对接全球华人！高提成销售职位虚位以待！客户群体为在美的华人，所以上班时间比较早！

一、岗位职责

1、 通过电话与美国的华人企业客户进行沟通，介绍公司产品，挖掘客户需求，积极跟进潜在客户，促成合作意向，完成销售目标。
2、 通过电话、网络等多种方式与客户建立联系，了解需求。
3、 演示和讲解我们的 POS 及餐饮管理系统解决方案的价值。
4、 完成销售目标，维护好与已合作客户的关系，及时反馈客户的意见和建议。

二、任职资格

1、 中专及以上学历，具有 2 年以上销售工作经验。
2、 普通话流利，具有主动沟通能力，具有较好的学习能力。
3、 有事业心、责任心和积极的工作态度，对销售工作有较高的热情。

三、薪酬福利

1、 我们拥有完善的培训、支持体系，助您无忧开拓：
   ① 系统化培训：从产品知识、销售技巧到客户管理，提供全套专业培训。
   ② 全程带教：经验丰富的导师全程指导；新人期由资深经理或导师从旁指导，陪你谈客户、分析案例，直至你独立完成签单。
   ③ 体系化支持：售前、售后及研发团队全力配合，为您提供强大的后端支援，确保您无后顾之忧。
   ④ 发展空间：销售专员→资深顾问→团队主管；不设天花板，只认能力值——你的潜力，就是晋升的刻度。
2、 我们拥有极具竞争力的薪酬福利：
   ① 稳步向上的薪酬：具有“持续性提成”是最大亮点。一旦客户使用，你就拥有一个“被动收入”管道。时间越长，积累的客户越多，收入越高越稳定。新人入职试用期 3400 元/月，转正 4000 元/月，人均基本 3 个月左右出单，1 年以上员工年稳定 1 万+/月，顶尖销售月入 4 万+。
   ② 稳稳的幸福：五险一金、员工体检、年假、节假日礼品等各类员工福利。
   ③ 快乐加油站：饮料、冰棍、小零食管够，快乐工作不打烊。

四、其他

超香作息：早 7 点上班，下午 3 点就下班！告别晚高峰，周末双休，拥有大把自由时光。

## 后端研发经理

一、岗位职责

1、 核心系统架构与开发：负责公司交易结算、供应链中台、商家服务、数据管控等核心业务系统的后端架构设计与核心代码开发，主导架构落地，保障系统高可用、高并发、低延迟、高可靠，支撑业务规模化扩张。
2、 技术攻坚与系统优化：牵头解决线上高并发瓶颈、数据库性能问题、分布式事务一致性、接口响应延迟等复杂技术难题；持续推进系统重构与性能优化，降低故障率及运维成本，保障业务稳定运行。
3、 技术迭代与架构演进：主导技术选型与架构整体规划，结合行业主流技术实践，推进微服务、K8s 容器化、Service Mesh 服务网格等新技术调研与落地，驱动架构迭代升级，提升研发效率与系统可扩展性、稳定性。
4、 规范搭建与质量管控：制定并落地后端开发、代码评审、接口设计等标准化规范，搭建研发流程与 DevOps 体系；主导单元测试、集成测试及自动化测试体系建设，全流程把控项目交付质量，保障代码规范与系统健壮性。
5、 团队搭建与能力建设：负责后端研发团队搭建与管理（过往管理团队规模不低于 10 人），统筹招聘、任务分配、绩效考核及员工职业发展；组织技术分享与技能培训，沉淀技术最佳实践，提升团队整体技术与业务能力。
6、 跨部门协同与项目交付：联动产品、前端、测试、运维等团队，深度拆解业务需求并转化为可落地技术方案，统筹内外部资源、把控项目迭代节奏，保障项目高质高效交付，助力业务提质增效。

### 二、任职要求

1、 学历与从业经验：本科及以上计算机相关专业，10 年以上后端开发经验，含 2 年以上大型分布式系统设计经验、2 年以上后端团队管理经验（管理规模 10 人+）；有 SaaS、高并发业务管理经验，日活百万级/QPS 过万系统研发运维经验，或美团、客如云、哗啦啦等同类企业从业经历者优先。
2、 核心语言能力：精通 Java（Spring Boot/Spring Cloud）或 Go 语言，深入理解 JVM/Go 运行时原理、内存模型及调优方式，可独立完成核心模块开发与架构搭建，熟练运用主流开源框架解决业务技术问题。
3、 数据库能力：精通 MySQL，具备复杂 SQL 优化、ShardingSphere/MyCat 分库分表、数据库高可用架构实战经验；熟练掌握 Redis 核心结构与集群方案，可解决缓存穿透、雪崩、击穿等问题，有海量数据存储优化经验者优先。
4、 中间件应用能力：深入理解 Kafka/RocketMQ 核心原理，可解决消息堆积、顺序消费、幂等性等核心问题；熟悉 Nginx、Elasticsearch 等中间件部署、配置与优化，可结合业务选型落地、提升系统性能。
5、 分布式架构能力：精通微服务架构设计，熟练掌握限流、熔断、降级等服务治理能力，掌握 Seata/TCC 分布式事务、Redis/Zookeeper 分布式锁等核心技术，可独立设计高可用、可扩展的分布式系统，具备微服务架构落地迭代经验。
6、 运维与问题排查：熟悉 Linux 系统，擅长线上 CPU、内存、IO 等疑难问题排查；了解 Docker、K8s 容器化部署，可推动自动化部署落地，熟悉 CI/CD 流程者优先；有 Flink/Spark 大数据处理、AI 工程化落地经验，或交易结算、供应链、SaaS 系统研发管理经验者优先。
7、 综合能力：具备优秀的复杂项目统筹、跨部门资源协调能力，有从 0 到 1 搭建团队、主导大型系统重构经验者优先；拥有高质量开源项目、技术博客，在技术社区有影响力，具备良好技术沉淀与分享能力者优先。

该样例未提供薪酬福利及其他信息。新 JD 应按当前岗位资料补充，不从其他样例推断。
